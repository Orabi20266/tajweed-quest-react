# رحلة الإتقان في أحكام التجويد — نسخة React

نسخة محسّنة من لعبة تعليمية عربية للأطفال لتعلّم أحكام التجويد، مبنية بـ **React + Vite**.
تحتوي على **10 مراحل** و**103 أسئلة**، مع شخصية المدرّب الكرتونية **إيهاب** التي تشرح الحكم عند الخطأ.

## المزايا

- **10 مراحل متدرّجة** مع فتح المرحلة التالية بعد اجتياز الحالية بنسبة 70% أو أكثر.
- **103 أسئلة** مستوحاة من منهج أحكام التجويد في موقع سورة قرآن.
- **خلط الأسئلة والخيارات** في كل محاولة، فلا يتكرر الترتيب نفسه.
- **مؤقّت مرن**: دقيقة واحدة لكل سؤال، ويتوقف تلقائياً عند ترك النافذة.
- **شخصية إيهاب** مع فقاعة شرح وزر استماع للنطق العربي (Web Speech API).
- **مؤثرات صوتية** مولّدة بـ Web Audio بدون أي ملفات خارجية.
- **حفظ التقدم** على الجهاز، مع نسخة مرتبطة بعنوان IP للعودة من نفس الشبكة.
- **ترحيل تلقائي** لتقدم النسخة القديمة (`tajweed_quest_v1`) عند توفره على نفس النطاق.
- **استئناف المحاولة** غير المكتملة بعد إغلاق الصفحة أو الخروج.
- **مراجعة الأخطاء** بعد كل محاولة مع الإجابة الصحيحة والشرح.
- **نجوم ونتائج قياسية** وأوقات أسرع لكل مرحلة.
- **اختصارات لوحة المفاتيح**: الأرقام 1–4 للإجابة، Enter للانتقال، Esc للخروج.
- **إتاحة**: دعم قارئ الشاشة، حالات تركيز واضحة، واحترام `prefers-reduced-motion`.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على http://127.0.0.1:5173
npm run build    # نسخة الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
npm run deploy   # بناء ونشر على Cloudflare Workers
```

## البنية

```
src/
├── App.jsx                 # حالة التطبيق، المؤقت، الجلسات، النوافذ
├── main.jsx                # نقطة الدخول
├── styles.css              # نظام التصميم والتجاوب
├── components/             # إيهاب، المؤقت، الخيارات، النوافذ، القصاصات…
├── hooks/
│   ├── useProgress.js      # حفظ التقدم محلياً وربطه بعنوان IP
│   ├── useSound.js         # مؤثرات Web Audio
│   └── useSpeech.js        # النطق العربي
├── lib/game.js             # خلط الأسئلة، النسب، النجوم، التحفيز، التخزين
├── screens/                # الرئيسية، الاختبار، النتيجة
└── data/levels.js          # بنك الأسئلة (10 مراحل / 103 أسئلة)
```

## التخزين

- المفتاح الأساسي: `tajweed_react_v1`
- نسخة مرتبطة بالشبكة: `tajweed_react_ip_<ip>` (عبر `api.ipify.org`، مع تراجع آمن إلى الحفظ المحلي وحده عند تعذّر الاتصال).

## النشر

المشروع ينتج موقعاً ثابتاً في `dist/`، ويعمل على:

- **GitHub Pages:** https://orabi20266.github.io/tajweed-quest-react/
- **المستودع:** https://github.com/Orabi20266/tajweed-quest-react

للنشر على Cloudflare من هذا المجلد:

